## 🚀 Overview
RecoAI is an intelligent movie recommendation system that combines
Content Based Filtering and Collaborative Filtering to provide
personalized movie recommendations — similar to Netflix and Amazon!

## 🎯 Problem Statement
With 500,000+ movies available today, users struggle to find
what to watch next. RecoAI solves this by analyzing user behavior
and movie features to provide instant personalized recommendations!
